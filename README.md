# SafariPiP

A Safari extension that forces any playing video into Picture-in-Picture,
including embedded players. Adds a toolbar button and a **⌘⇧P** keyboard
shortcut.

## How it works

- `extension/` holds the WebExtension source (Manifest V3).
  - `manifest.json` — declares the toolbar action, the ⌘⇧P command, and only
    the `activeTab` + `scripting` permissions (no persistent "read all sites"
    access; permission is granted per-click).
  - `background.js` — service worker. On button click or ⌘⇧P, injects `pip.js`
    into every frame of the active tab. Flashes a `?` badge if no video was
    found, `!` if the page can't be scripted.
  - `pip.js` — injected per frame. Picks the best video (visible, prefer
    playing, largest), clears any restriction on entering Picture-in-Picture,
    and toggles PiP via Safari's `webkitSetPresentationMode` (falls back to
    `requestPictureInPicture`).
- `SafariPiP/` is the Xcode app wrapper generated by
  `safari-web-extension-converter`. The built app is what Safari loads.

## Requirements

- macOS with Xcode installed (the full app, not just the Command Line Tools).
- A free Apple ID is enough to sign and run the extension locally.

## Building and installing

```sh
git clone <this-repo-url>
cd SafariPiP

# Generate the Xcode project from the extension source (first time only)
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcrun safari-web-extension-converter extension \
  --project-location . --app-name SafariPiP \
  --swift --macos-only --copy-resources --no-open --no-prompt --force
```

Open `SafariPiP/SafariPiP.xcodeproj` in Xcode, select the `SafariPiP` target,
and set **Signing & Capabilities ▸ Team** to your own Apple ID (Automatic
signing). Then build and run (⌘R), or from the command line:

```sh
cd SafariPiP
xcodebuild -project SafariPiP.xcodeproj -scheme SafariPiP -configuration Release \
  -derivedDataPath build CODE_SIGN_STYLE=Automatic build
cp -R build/Build/Products/Release/SafariPiP.app /Applications/
open /Applications/SafariPiP.app
```

Launching the built app once registers the extension with Safari.

## Enabling in Safari

1. Open **Safari ▸ Settings ▸ Extensions**.
2. Tick **SafariPiP**.
3. Click the SafariPiP toolbar button on any video page. Safari will ask for
   permission for that site — choose **Allow** (or "Always Allow on Every
   Website" for one-and-done).

Then click the button (or press ⌘⇧P) on any video to pop it into PiP; click
again to send it back inline.

## Rebuilding after edits

Edit files under `extension/`, then sync and rebuild:

```sh
cp -R extension/. "SafariPiP/SafariPiP Extension/Resources/"
cd SafariPiP
xcodebuild -project SafariPiP.xcodeproj -scheme SafariPiP -configuration Release \
  -derivedDataPath build CODE_SIGN_STYLE=Automatic build
rm -rf /Applications/SafariPiP.app
cp -R build/Build/Products/Release/SafariPiP.app /Applications/SafariPiP.app
open /Applications/SafariPiP.app
```

Regenerating the icons (only if you change the glyph): `python3 make_icons.py`
renders `icon-512.png`, then downscale with
`cd extension/images && for s in 256 128 96 48; do sips -z $s $s icon-512.png --out icon-$s.png; done`.

## Notes

- Signing with your own Apple ID keeps the extension enabled across Safari
  restarts — no need to toggle "Allow Unsigned Extensions" in the Develop menu.
- Keep the installed `SafariPiP.app` in place; deleting it unregisters the
  extension.
